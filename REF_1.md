## 13. АНИМАЦИИ И SCROLL-ЭФФЕКТЫ

### Scroll-triggered (при скролле)

Все секции и карточки появляются при входе в viewport:

```css
/* Начальное состояние (hidden) */
opacity: 0;
transform: translateY(30px);

/* Конечное состояние (visible) */
opacity: 1;
transform: translateY(0);
transition: opacity 0.6s ease-out, transform 0.6s ease-out;
```

**Stagger (задержка для дочерних элементов):**

- Карточки в сетке появляются поочерёдно (задержка 0.1–0.15s на каждую)
- Реализуется через `animation-delay` или JS IntersectionObserver

### Hover-анимации


| Элемент                | Эффект                              |
| ---------------------- | ----------------------------------- |
| CTA-кнопка             | Потемнение фона + тень              |
| Карточка               | `translateY(-5px)` + усиление тени  |
| Изображение в карточке | `scale(1.05)`                       |
| Фото в галерее         | `scale(1.05)` + тёмный overlay      |
| Ссылки в меню          | Изменение цвета (белый → оранжевый) |
| Иконка в кнопке        | `translateX(3px)`                   |
| Карточка отзыва        | Усиление тени                       |


### Sticky Header

```javascript
// При скролле > 50px:
header.classList.add('scrolled');
// .scrolled { box-shadow: 0 2px 20px rgba(0,0,0,0.3); }
transition: box-shadow 0.3s ease;
```

### Параллакс (возможно)

- Фоновое изображение в hero-секции скроллится медленнее контента
- `background-attachment: fixed` или JS-реализация
- Скорость: 0.5x от скорости скролла

### Счётчики / Цифры

- При попадании секции в viewport цифры анимированно «считаются» (0 → конечное значение)
- Duration: ~1.5–2s
- Easing: ease-out

- **Открытие:** `opacity: 0 → 1` + `translateX(-100%) → translateX(0)` или `scale(0.95) → scale(1)`
- **Закрытие:** обратный эффект
- **Duration:** `0.3–0.4s`
- Гамбургер превращается в «✕» через анимацию поворота линий

## 18. КАРТА И КОНТАКТЫ

### Секция контактов

- Split-screen: карта слева / контактные данные справа
- Карта: Яндекс Карты embed (iframe), интерактивная
- Метка на клинике/клубе
- Контактная информация: иконка + текст
  - Телефон (кликабельная ссылка `tel:`)
  - Адрес
  - Режим работы
  - Иконки соцсетей

## 19. ХЛЕБНЫЕ КРОШКИ (BREADCRUMBS)

На внутренних страницах:

```
Главная / Текущий раздел
```

- Цвет: серый
- Разделитель: `/` или `›`
- Текущая страница: жирным или без ссылки
- Размер: ~14px
- Позиция: верх страницы, под хедером

## 20. STICKY FLOATING-КНОПКА

- Позиция: правый нижний угол, фиксированная (`position: fixed`)
- Иконка: телефон или чат
- Фон: оранжевый `#FF7A00`
- Форма: круглая (`border-radius: 50%`)
- Тень: `box-shadow: 0 4px 15px rgba(255, 122, 0, 0.5)`
- Hover: `transform: scale(1.1)`
- Появляется после скролла ~300px вниз

## 21. УВЕДОМЛЕНИЯ И СОСТОЯНИЯ

### Cookie-уведомление

- Позиция: снизу экрана (fixed)
- Фон: светло-серый
- Текст + кнопки «Принять» / «Настроить»
- Появляется при первом визите

### Сообщение об успехе формы

- Всплывающее уведомление или замена формы
- Цвет: зелёный фон + белый текст
- Иконка: ✓
- Fade-in анимация

### Состояние загрузки кнопки

- Текст заменяется на спиннер (CSS анимация вращения)
- Или добавляется спиннер рядом с текстом
- Кнопка становится disabled

## 24. СПИННЕРЫ ЗАГРУЗКИ

### Загрузка страницы

- Возможно: полноэкранная заглушка (preloader) с логотипом
- Анимация: fade-out при загрузке страницы
- Или: нет preloader (Tilda загружает быстро)

### Спиннер в кнопке формы

```css
@keyframes spin {
  0%   { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
.spinner {
  width: 20px; height: 20px;
  border: 2px solid rgba(255,255,255,0.3);
  border-top-color: #FFFFFF;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```

### Lazy loading изображений

- Плейсхолдер: размытое изображение (blur-up) или серый фон
- Transition от blur к чёткому: `filter: blur(5px) → blur(0px)`, `0.4s`

## 25. ДЕКОРАТИВНЫЕ ЭЛЕМЕНТЫ

### Волнистое подчёркивание заголовков

- Голубая волнистая линия (`~00A0E9`) под ключевым словом в H2
- Реализация: CSS `text-decoration: underline wavy` или SVG-линия
- Появляется только у определённых слов (не всего заголовка)

### Бейджи (badges)

- **Бейдж возраста на карточке:** белый фон, чёрный текст, pill-shape, positioned overlay
- **Бейдж «ШАГ №X»:** white-border pill, оранжевый текст

### Теги / Метки

- Оранжевые pill-shape плашки над блоками
- Например: «Направления тренировок», «О клубе», «Отзывы», «Фотогалерея»
- Стиль: маленький текст, uppercase, оранжевый фон или обводка

### Разделители секций

- Нет явных линий-разделителей
- Чередование фонов создаёт визуальные границы
