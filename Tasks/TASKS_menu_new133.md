## Изменения

### 1. Уменьшить размер шрифта заголовков

**Цель:** кнопки-аккордеоны «Наши услуги», «Компания», «Специалисты» и простые ссылки «Наши работы», «Цены», «Акции», «Контакты» должны быть визуально меньше.

**Что менять:**
- `.nav__group-toggle` — `font-size: 19px` → **`15px`** (или `16px`, по результату)
- `.nav__mobile-item > a` — `font-size: 19px` → **`15px`** (одинаково с toggle)

Оба класса уже имеют одинаковый `font-size: 19px`, поэтому правим синхронно.

---

### 2. Сдвинуть логотип ниже

**Цель:** логотип `.nav__logo` должен иметь чуть больше отступа сверху, чтобы не прижиматься к верхнему краю панели.

**Что менять:**
- `.nav__logo` — увеличить `margin-top` (сейчас `margin: 4px 0 28px`) → сделать `margin: 20px 0 20px` (точное значение уточнить визуально, стартовое — **`20px`** сверху)

> Кнопка `×` стоит `position: absolute; top: 16px; right: 16px` — на неё не влияет.

---

### 3. Зафиксировать верхнюю часть панели, раскрытие только вниз

**Цель:** логотип + кнопка × не должны уезжать вверх при раскрытии аккордеона; скролл идёт только внутри списка навигации.

**Текущее состояние:** `.header__nav` уже имеет `overflow-y: auto` на всю панель, из-за чего всё содержимое прокручивается вместе.

**Решение:**

1. Обернуть прокручиваемую зону в отдельный div `.nav__scroll-area` **в `index.html`** — _или_ сделать это через CSS, не трогая разметку.

   **Вариант без правки HTML (CSS-only):**
   - `.header__nav` → убрать `overflow-y: auto`, оставить `display: flex; flex-direction: column`
   - `.nav__logo` → `flex-shrink: 0` (фиксируется вверху)
   - `.nav__mobile` → `overflow-y: auto; flex: 1; min-height: 0` — прокручивается только эта зона
   - `.nav__divider` + `.nav__contact` попадают **внутрь** `.nav__mobile` в разметке — проверить по `index.html` строки 221–270. Если они уже внутри `.nav__mobile` (они там есть), то `overflow` на `.nav__mobile` захватит их тоже — ок.
   - `.nav__cta` → `flex-shrink: 0; margin-top: 0` + добавить `padding-bottom: 32px` к `.nav__mobile` вместо отступа

   > Кнопка `nav__cta` находится **вне** `.nav__mobile` (после него в HTML). Поэтому она автоматически останется "прибитой" снизу благодаря `margin-top: auto` + `flex-shrink: 0` на родителе `.header__nav`.

**Итоговые правки CSS:**
```
.header__nav         → убрать overflow-y: auto
.nav__logo           → flex-shrink: 0
.nav__mobile         → overflow-y: auto; flex: 1; min-height: 0
.nav__cta            → flex-shrink: 0 (margin-top: auto уже стоит)
```

---

### 4. Уменьшить разрыв между заголовками

**Цель:** убрать лишние вертикальные отступы между пунктами меню.

**Что менять:**
- `.nav__group-toggle`, `.nav__mobile-item > a` — `min-height: 48px` → **`38px`** (или `36px`)
- `.nav__group` — добавить `margin: 0` или убрать возможный `padding`
- `.nav__group.is-open .nav__group-body` — `margin: 4px 0 12px` → `margin: 2px 0 8px` (немного сжать)

## Порядок применения

1. Открыть `css/sections/header.css`, перейти к `@media (max-width: 992px)` (~строка 518).
2. Применить изменения **шага 1** (font-size).
3. Применить изменения **шага 2** (margin логотипа).
4. Применить изменения **шага 3** (overflow/flex для фиксации шапки панели).
5. Применить изменения **шага 4** (min-height, margin аккордеонов).
6. Проверить на ширинах 320px, 375px, 480px.

---

## Ограничения

- Изменения применяются **только** в блоке `@media (max-width: 992px)` — не затрагивать десктопные стили.
- Разметку `index.html` **не трогать** (CSS-only решение для п.3).
- Другие страницы (`xxx/index.html`) не имеют `.nav__mobile` — изменения на них не распространяются.
